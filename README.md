# Minigames

This project is a task from the Rolling Scopes School [Front-end Short track](https://rs.school/courses/short-track) course.

## Key skills

- Valid semantic responsive web design;
- Easy-to-maintain, readable code;
- Exporting styles and graphics from Figma;
- Using TypeScript to implement the functionality specified in the task.

## Technology stack

- TypeScript;
- HTML + SCSS;
- Vite;
- Husky;
- ESLint, Prettier.
